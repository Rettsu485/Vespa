# 💊 MedTrack — учёт приёма лекарств

Веб-приложение вместо таблицы Excel: карточки лекарств на день, отметки приёма
с подсветкой (как зелёные ячейки), расчёт промежутков между дозами и предупреждения
о слишком коротких интервалах. Данные хранятся в локальном SQLite-файле.

## Запуск
```bash
pip install -r requirements.txt
python app.py            # → откройте http://localhost:5000
```

## Возможности
- **Вкладка «День»** — карточка на каждое лекарство по плану на выбранную дату:
  тип (💊 таблетки, 💧 капли, 🥤 сироп, 💉 укол…), дозировка, описание, цвет,
  статус (⏳ / 🟡 / ✅), число принятых доз, **промежутки между приёмами в часах**,
  кнопка «Принято сейчас» (с выбором времени и заметкой) и отмена ошибочной записи.
  Сверху — ⚠️ предупреждения, если промежуток меньше рекомендованного для частоты
  (1× → 24 ч, 2× → 12 ч, 3× → 8 ч, 4× → 6 ч).
- **Вкладка «Лекарства»** — справочник: название, тип, дозировка, описание, цвет,
  архивирование (лекарства можно менять когда угодно, история сохраняется).
- **Вкладка «Расписание»** — планы приёма с датами действия «с … по …»: лекарства,
  которые меняются каждый день, описываются новым планом, старые просто заканчиваются.
- **Вкладка «История»** — тепловая таблица «дата × лекарство» за N дней.
- **Импорт из Excel** (.xlsx): понимает вашу текущую таблицу — строка заголовков =
  названия лекарств, ниже = время приёма, светло-зелёная заливка ячейки = «принято»,
  дата слева (в том числе в объединённой ячейке — распространяется на строки ниже).
