# Штаб

Локальный настольный рабочий трекер (Electron + React + TypeScript + SQLite) для одного пользователя. Без интернета, без облака: все данные хранятся в локальном файле SQLite в папке userData приложения.

## Модули

- **Дашборд «Сегодня»** — счётчики просрочек, горящие документы ЭДО, красные флаги мониторингов, дни рождения и возвращения из отпусков.
- **Команда** — справочник сотрудников (список/дерево по отделам), вычисляемые статусы (отпуск/командировка/больничный/уволнен), таймлайн отсутствий на 60 дней.
- **Мониторинги** — кто что ведёт: группировка по сотрудникам, матрица «сотрудники × типы», дублёры и красные флаги.
- **ЭДО** — личный журнал документов: контроль сроков (красный/зелёный), лист согласования, журнал проделанной работы.
- **Задачи** — список и канбан, чек-листы с прогрессом, режим ожидания с датой возврата, индикатор заброшенности.
- **Настройки** — справочник типов задач, названия типов контроля, шаблон ссылки на документ ЭДО, тема, плотность таблиц, резервные копии, демо-данные.

## Запуск (Windows)

Требуется Node.js LTS ≥ 20.

```powershell
cd shtab
npm install          # восстановление зависимостей (или npm ci)
npm run dev          # режим разработки: Vite + Electron
npm run typecheck    # проверка типов
npm run build        # прод-сборка renderer + main
node scripts/smoke-db.mjs   # смоук-тест слоя БД
```

Горячие клавиши: `Ctrl+K` — глобальный поиск; в формах `Enter` — сохранить, `Esc` — закрыть. Минимальная ширина окна — 1100 px.

## Репозиторий

**Никогда не коммитится** (см. `.gitignore`):

- `node_modules/` — зависимости восстанавливаются командой `npm ci` (или `npm install`) в папке `shtab`;
- артефакты сборки: `dist/`, `dist-electron/`, `out/`, `release/`, `build/`, `*.exe`;
- файлы базы данных и бэкапы: `*.db`, `*.db-wal`, `*.db-shm`, `backups/`, `.smoke/` (тестовая БД);
- логи и `.env`.

**Страхующий хук:** в репозитории подключён `pre-push`-хук (`.githooks/pre-push`, активирован через `git config core.hooksPath .githooks`). Он блокирует push, если в отправляемых коммитах находится файл тяжелее 90 МБ (лимит GitHub — 100 МБ). Хук версионирован в репозитории; после клонирования достаточно один раз выполнить `git config core.hooksPath .githooks`.

Если большой файл случайно попал в историю — вычистить её можно так (на Windows — Git Bash):

```sh
pip install git-filter-repo
git filter-repo --invert-paths --path-regex '(^|/)node_modules/.*' --force
git reflog expire --expire=now --all && git gc --prune=now --aggressive
git remote add origin <URL>
git push -u origin main --force
```
